4. PAYMENT GATEWAY IMPLEMENTATION & HOST UPI QR DETAILS
================================================================================

Payment Philosophy:
- As requested, third-party payment partner integration is on hold until merchant
  onboarding completes.
- In the meantime, the software features a full **Host Direct UPI QR Gateway**:
  1. The event/movie host defines their official UPI VPA (e.g., `pvr.cinemas@icici`)
     and Business Name (`PVR CINEMAS ENTERTAINMENT LTD`) via the Host Studio portal.
  2. When a customer confirms their seats, the backend constructs an official NPCI
     UPI URI string:
     `upi://pay?pa={HOST_UPI}&pn={HOST_NAME}&am={AMOUNT}&cu=INR&tn=Ticket-{BOOKING_ID}`
  3. The backend renders this into a dynamic high-resolution QR Code (Data URL PNG).
  4. The customer scans the QR code using any UPI app (GPay, PhonePe, Paytm, BHIM)
     where the exact booking amount is pre-filled.
  5. The customer can either enter the 12-digit transaction UTR number or click
     "Instant UPI Payment Simulation (1-Click)" to immediately verify the payment.
  6. Upon verification, the booking is permanently CONFIRMED and the E-Ticket with
     entrance QR code is instantly issued.

Attaching Real Payment Partners (Razorpay / Stripe):
-----------------------------------------------------
The architecture in `backend/services/PaymentService.js` contains pluggable partner
adapters. To activate Razorpay or Stripe:
1. Open `backend/.env` (or environment variables) and set:
   RAZORPAY_KEY_ID=your_actual_key_id
   RAZORPAY_KEY_SECRET=your_actual_key_secret
2. The `RazorpayAdapter` will automatically enable server-side order creation and
   webhook verification.

5. REST API ENDPOINTS SPECIFICATION
================================================================================

Authentication:
  POST   /api/auth/login               - Login with email, password, role
  POST   /api/auth/register            - Register user or host (with UPI ID)
  GET    /api/auth/me                  - Verify token session

Movies:
  GET    /api/movies                   - List movies (search, genre filters)
  GET    /api/movies/:id               - Get movie details and shows
  POST   /api/movies                   - Add new movie (Admin/Host)
  PUT    /api/movies/:id               - Update movie (Admin)
  DELETE /api/movies/:id               - Delete movie (Admin)

Theaters:
  GET    /api/theaters                 - List theaters by city or host
  GET    /api/theaters/:id             - Get theater details & screens
  POST   /api/theaters                 - Create theater venue (Host/Admin)
  PUT    /api/theaters/:id             - Edit theater (Host/Admin)
  DELETE /api/theaters/:id             - Delete theater (Admin)

Shows:
  GET    /api/shows                    - List scheduled shows (movie, date filters)
  GET    /api/shows/:id                - Get show details
  GET    /api/shows/:id/seats          - Get dynamic seat matrix (status & tiers)
  POST   /api/shows                    - Schedule new show (Host/Admin)
  PUT    /api/shows/:id                - Update show (Host/Admin)
  DELETE /api/shows/:id                - Delete show (Host/Admin)

Bookings:
  POST   /api/bookings/hold            - Temporary hold seats (10 min TTL)
  POST   /api/bookings/confirm         - Confirm booking after payment
  POST   /api/bookings/cancel/:id      - Cancel booking & release seats
  GET    /api/bookings/user/:userId    - User booking history
  GET    /api/bookings/host/:hostId    - Host bookings list
  GET    /api/bookings/all             - Admin all bookings list

Payments:
  POST   /api/payments/generate-upi-qr - Generate Host UPI QR code data URL
  POST   /api/payments/verify          - Verify payment & confirm booking
  GET    /api/payments/gateway-info    - Status of pluggable payment partners

Tickets:
  GET    /api/tickets/:id              - Get e-ticket details & QR code
  POST   /api/tickets/scan             - Cinema gate scanner entrance check-in

Reports:
  GET    /api/reports/admin            - Platform gross revenue & analytics
  GET    /api/reports/host/:hostId     - Host revenue, ticket sales, shows

Users:
  GET    /api/users                    - List all user accounts
  PATCH  /api/users/:userId/status     - Block / Unblock user account
  PUT    /api/hosts/:hostId/profile    - Update host UPI VPA and profile

6. HOW TO RUN THE APPLICATION
================================================================================

Prerequisites:
  - Node.js (v18 or higher, tested on Node v24)
  - npm (v9 or higher)

Step 1: Open Terminal in Project Directory
  cd C:\Users\mihir\.gemini\antigravity\scratch\eticket-system

Step 2: Run Both Backend & Frontend Simultaneously
  npm run dev

  - Backend starts on  : http://localhost:5000
  - Frontend starts on : http://localhost:3000

Step 3: Access in Browser
  Open your web browser and navigate to:
  http://localhost:3000

Step 4: Explore the 3 Roles
  - Customer View   : Browse movies, pick seats, hold seats, scan UPI QR, get ticket.
  - Host Studio     : Click 'Demo Roles' -> 'Host' or sign in as host@pvr.com.
                      Configure your UPI ID, schedule shows, and scan tickets.
  - Admin Console   : Click 'Demo Roles' -> 'Admin' or sign in as admin@eticket.com.
                      Manage movies, theaters, users, and review financial charts.
